# Product Overview

## PC28 Prediction System

AI/ML-powered lottery prediction system that combines statistical analysis with machine learning to predict PC28 lottery outcomes. The system uses second-order Markov chains, exponential moving averages, and tail frequency analysis to generate predictions with target accuracy of 65-70% for sum ranges and 56-61% for combination predictions.

## Core Features

- **Statistical Engine**: Second-order Markov chain with 5 states (大单, 小双, 小单, 大双, 极值)
- **Dynamic Analysis**: EMA with 3-7 periods and chi-square tail frequency testing
- **Real-time Integration**: Live PC28 data feeds with <2s response time
- **AI/ML Catalog**: Model extraction and categorization system
- **Performance Targets**: 99.9% uptime, statistical significance p<0.05
